1. Top Skills for Data Jobs
The objective of this analysis is to identify and evaluate the most in-demand technical skills in the global data job market. It focuses on understanding which technical skills employers frequently mention in job postings and how the demand for these skills varies across different data-related job roles.

By analysing the frequency of each skill across job postings, this analysis helps identify the technologies and tools that professionals should prioritise when developing their technical skill sets. It also allows users to filter job titles and explore role-specific skill requirements, providing a clearer understanding of the technical expectations for different positions.

2. Skills vs Salary Analysis
The objective of this analysis is to examine the relationship between technical skills and their associated salary levels in the global data job market. It identifies the top 10 highest-paying skills based on average salary and evaluates how frequently these skills appear across job postings.

This analysis helps understand which technical skills are associated with higher earning potential and how their demand compares in the job market. By combining average salary and skill count, it provides a broader perspective on the value and demand of different technical competencies.
Tools Used
Power Query: Cleaned and transformed the raw dataset to ensure data consistency and accuracy.
Power Pivot: Created the data model and supported analytical calculations.
Pivot Tables: Summarised skill counts and calculated average salaries for individual skills.
Pivot Charts: Created a combination chart to compare average salaries and skill demand
Slicers: Enabled interactive filtering based on different job titles.

Analysis Performed
Identified the top 10 skills based on average salary.
Calculated the average salary associated with each technical skill.
Analysed the number of job postings requiring each skill.

Compared salary levels against skill demand using a combination chart.

Used an interactive job title slicer to explore salary and skill patterns across different data-related roles.
