Skills Salary Analysis

Project Overview
Analysed the relationship between in-demand skills and their median salaries across different job roles and countries to help job seekers make informed career decisions.

How I Created It
1. **Data Preparation:** Cleaned and transformed the raw dataset using Power Query.
2. **Data Modelling:** Created relationships and calculated measures using Power Pivot and DAX.
3. **Pivot Table Analysis:** Summarised skills, median salaries and skills likelihood.
4. **Data Visualization:** Created a combination chart to compare median salaries and skills likelihood.
5. **Interactive Filtering:** Added Job Title and Job Country slicers with multi-select functionality.

Business Value for Job Seekers
- Identify skills associated with higher salaries.
- Understand the demand for different technical skills.
- Prioritize learning based on salary potential and market demand.
- Make informed career development decisions.

### Final Outcome
Developed an interactive Excel analysis that helps job seekers explore skill demand and salary trends across different job roles and countries.
